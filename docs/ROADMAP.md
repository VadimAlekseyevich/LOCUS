# LOCUS — Roadmap

Only current unfinished work is tracked here. See [GDD](GDD.md) for the game rules and [README](../README.md) for the available features.

## Next

- [ ] **Windows release:** Prepare a portable build or installer that runs on a clean Windows machine without CMake or Visual Studio.
- [ ] **Real-device QA:** Verify audio synchronization, input, song import, chart save/reopen, test play and safe exit on Windows.
- [ ] **Window sizes:** Check the centered square, clipping and right-side accuracy panel on wide, narrow and portrait windows.
- [ ] **Editor polish:** Validate the note-placement workflow, group edits, timing adjustments, shortcut conflicts and recovery from invalid file operations through hands-on use.
- [ ] **Publishing:** Choose a source license, release version and distribution instructions before publishing a release.

## Possible later features

Tempo changes, hold notes, waveform editing, automatic BPM detection, pitch-preserving practice speed and online services are **not** part of the current implementation plan unless requested.
